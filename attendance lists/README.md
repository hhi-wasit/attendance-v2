# Attendance lists

Upload the six Excel workbooks to this folder using these exact filenames:

- `emergency.xlsx`
- `midwifery.xlsx`
- `nursing A.xlsx`
- `nursing B.xlsx`
- `nursing C.xlsx`
- `nursing D.xlsx`

Each workbook should have a header row containing at least the student number column (`ت` or `ID`) and the student name column (`اسم الطالب الثلاثي` or `Name`). Optional columns such as department, stage, and group are also displayed in the attendance report.
